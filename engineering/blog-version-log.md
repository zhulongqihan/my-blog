## 2026-10-26 管理台草稿保存与超时重试修复

修正新建文章响应超时后再次保存可能创建另一篇文章的问题。管理台为每次创建持久保存稳定请求标识和原始输入；未知结果时重放原操作取得文章ID，再更新当前修改。已取得ID后始终更新同一文章，刷新或跳转失败也可恢复。后端在真实数据库事务中同时写入文章和创建凭据，按作者与请求标识建立唯一约束；同标识不同输入返回409，文章删除后的旧请求返回410，不按标题合并文章。

保存与后台详情响应使用数据库计数，移除可选Redis点赞读取；提交后的缓存、热榜与Feed处理、操作审计发送分别进入有界后台队列，队列满或依赖失败不会改变已经提交的保存结果。公开正文、摘要和归档继续按数据库发布状态及版本校验。后台列表在分页后批量读取关联信息及评论数，避免逐篇访问关联与评论表；前端列表仅接受最新查询的结果与加载状态。

部署前需显式应用`backend/src/main/resources/db/manual/V20261026__article_creation_requests.sql`，只新增独立凭据表，保留原文章结构及数据。回退应用仍保留凭据表；已上线新客户端后回退到不支持幂等的旧后端，须先暂停新建操作。有界投影和审计队列是内存队列，进程退出或队列拒绝可能丢失这些非关键任务；此版本不把它描述为持久任务队列。

本地验收：后端Maven verify执行81项测试，0失败/错误；覆盖真实H2事务、并发重放、丢失响应后的恢复、回滚、删除凭据保留、Redis/MQ阻塞和队列拒绝、撤回与发布一致性、分页批量查询。真实Redis专项用例需独立Redis环境，本轮未重跑。管理台26项Node回归、生产构建及21项真实浏览器夹具检查通过，包含实际等待15秒超时、分类清空后的恢复及旧页面迟到响应不抹新输入；浏览器仅使用假身份和本地拦截接口。线上验收将在实际发布后补记。

## 当前版本变更

### 文章初始化边界

- 线上 MySQL 是文章事实来源；生产应用启动不再创建、重置或同步文章。
- 新增 `blog.demo.seed-content` 开关：开发环境显式开启，生产环境默认关闭。
- 生产发布只重建 backend 容器，不重建 MySQL、Redis、RabbitMQ 数据卷；线上已有文章保持不变。

### AI Gateway 与阅读助手

- 博客前端通过同源 `/api/ai/chat` 访问 Spring Boot AI Gateway，不在浏览器保存模型密钥。
- Gateway 在服务端按文章 ID 和关键词检索已发布文章，给模型提供受控上下文。
- SSE 响应包含 `meta`、模型增量内容和 `[DONE]`，前端展示检索来源并支持流式阅读。
- Redis 记录 `requestId`、检索数量、首字节延迟、总耗时、字符数和错误状态，博客后台提供最近调用轨迹查看能力。
- `/api/mcp` 提供最小只读 MCP JSON-RPC 接口，暴露 `search_articles` 和 `get_article` 两个博客内容工具。
- 当前检索实现是有边界的标题、摘要、正文词法评分，不应包装为已经落地 Milvus、BM25、向量召回或 rerank。

### 线上修复

- 浏览器验收发现生产环境变量仍指向旧的 `/ai-api`，导致阅读助手请求返回 405。
- 已将博客生产配置切换为 `/api/ai`，重新构建前端并发布 Nginx 静态产物。
- `aiApi.ts` 现在固定使用同源 `/api/ai`，Vite 已删除废弃的 `/ai-api` 直连代理，避免未来环境文件残留导致回归。
- 该修复只涉及博客前端配置和博客部署静态资源，没有修改航旅 Agent。
